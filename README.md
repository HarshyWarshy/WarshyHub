# WarshyHub

WarshyHub is a refined, dark-theme AP World History study website with in-depth pages for units, timeline review, thematic writing, practice routines, and focus music resources.

## Pages

- `index.html` — central hub linking every study mode.
- `units.html` — AP World units page with timeline/unit-specific links.
- `timeline.html` — period-by-period developments and evidence.
- `themes.html` — thematic writing frameworks and templates.
- `study-tools.html` — practical routines, checklists, and planning tools.
- `practice.html` — rotating prompts and drill flow.
- `focus-music.html` — website theme presets + non-copyright music resource links.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server.
