# WarshyHub

WarshyHub is a refined, dark-theme AP World History study website with in-depth pages for timeline review, thematic writing, and exam-style practice.

## Pages

- `index.html` — central hub with study paths, button-style resource links, and weekly plan.
- `timeline.html` — detailed period-by-period developments, evidence banks, and exam angles.
- `themes.html` — deep theme framework, comparison sets, and thesis/paragraph templates.
- `practice.html` — rotating prompts, multi-round routines, scoring checklists, and resource buttons.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server.
