Practice Like Test Day: Prompt Generator + Writing Systems

Use this page for daily reps. Generate random prompts, then pair each with a short plan using the checklists below so your writing gets faster and clearer.

Prompt Generator

10-Minute Response Routine

Minute 1–2: Decode

  • Circle command terms (compare, evaluate, explain).
  • Underline time range and region requirements.
  • Choose one claim you can defend with evidence.

Minute 3–4: Plan

  • Write a thesis sentence with a clear line of reasoning.
  • List 2–3 specific examples from different places or times.
  • Add one contextual sentence before your argument.

Minute 5–10: Write

  • Use topic sentence → evidence → explanation pattern.
  • Always connect evidence back to the argument.
  • End with a comparative or continuity insight if possible.

DBQ / LEQ Mini Checklists

Task Must Include Common Miss
DBQ Thesis, context, doc evidence usage, sourcing for at least some docs. Quoting docs without explaining why they matter.
LEQ Direct claim, specific historical evidence, and reasoning chain. General statements with no named people/events/processes.
SAQ Answer all parts clearly with one specific fact each. Repeating the prompt language without adding evidence.
